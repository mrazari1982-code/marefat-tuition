# سامانه شهریه مجتمع آموزشی دخترانه معرفت

نسخه آزمایشی مستقل شامل پنل اولیا، پنل حسابداری و APIهای نمایشی.

## اجرای محلی با Express

```bash
npm install
npm start
```

## آزمون

```bash
npm test
```

## انتشار در Netlify

تنظیمات انتشار در `netlify.toml` قرار دارد. پوشه `public` به‌عنوان سایت
استاتیک منتشر می‌شود و APIها از `netlify/functions` ارائه می‌شوند.
